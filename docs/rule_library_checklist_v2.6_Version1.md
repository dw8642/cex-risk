# 风控规则库沟通与确认 Checklist（V2.6）

## 0. 使用说明

本文档用于和：

- 老板
- 交易员 / 交易负责人
- 风控负责人
- 产品经理
- 研发负责人

逐条确认风控规则库项目。

本清单重点回答以下问题：

1. 这条规则要不要做？
2. 为什么做？
3. 优先级是什么？
4. 数据来源是否具备？
5. 阈值由谁定？
6. 告警等级怎么分？
7. 触发后系统动作是什么？
8. 是否需要自动恢复？
9. 是风控平台做，还是策略引擎做？
10. 当前是否已经确认，是否可进入研发排期？

## 1.1 E-002A 单市场仓位集中风险

- **规则编号**：E-002A
- **规则名称**：单市场仓位集中风险
- **优先级**：P0
- **规则层级**：平台统一主规则库
- **来源规则**：RISK-POS-001
- **风险对象**：账户 + 市场 / 交易所 + 标的
- **业务目的**：防止单一市场仓位过度集中，导致方向性风险失控
- **数据来源**：
  - Position Snapshot
  - Mark Price
- **监控参数 / 指标**：
  - `position_qty`
  - `mark_price`
  - `position_usd = abs(position_qty) * mark_price`
- **适用范围**：
  - 单账户 + 单市场
  - 可扩展到单交易所所有账户 + 单市场
- **规则条件**：
  - `position_usd > per_market_exposure_limit`
- **阈值配置项**：
  - `per_market_exposure_limit`
- **阈值由谁定**：
  - [ ] 交易员建议
  - [ ] 风控最终生效
  - [ ] 老板确认总预算
- **告警等级建议**：
  - L1：轻度超限
  - L2：明显超限
  - L3：严重超限且持续
- **系统动作建议**：
  - L1：普通告警
  - L2：降级
  - L3：降级 / 暂停该策略
- **恢复条件建议**：
  - 连续 2 个窗口回到阈值内
  - 是否自动恢复需确认
- **实现归属**：risk_platform
- **待确认问题**：
  - 是否按账户看，还是按“单交易所所有账户持仓”看？
  - Spot / Futures 是否分开阈值？
- **确认状态**：
  - [ ] 已和交易员确认
  - [ ] 已和老板确认优先级
  - [ ] 已确认数据来源
  - [ ] 已确认阈值归属
  - [ ] 已确认告警等级
  - [ ] 已确认系统动作
  - [ ] 已确认恢复条件
  - [ ] 已确认实现归属
  - [ ] 可进入研发排期
